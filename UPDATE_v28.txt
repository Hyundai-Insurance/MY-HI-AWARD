MY 아듀 2026 — 신규 백데이터 양식 적용 (v28)

이 ZIP은 기존 저장소에 덮어쓰는 수정본입니다.
기존 파일과 폴더는 삭제하지 마세요. 기존 디자인·하이스타·하이포인트·GA4 설정을 유지합니다.

1. GitHub Desktop에서 MY-HI-AWARD / main 저장소를 선택합니다.
2. Repository > Show in Explorer로 실제 저장소 폴더를 엽니다.
3. ZIP 내부 파일을 해당 폴더 최상위에 덮어씁니다.
   app.js와 index.html이 기존 파일과 같은 위치여야 합니다.
4. GitHub Desktop에서 변경 목록을 확인하고 Commit to main → Push origin 합니다.
5. GitHub Actions의 Build & deploy가 성공한 뒤 사이트를 새로고침합니다.
   로컬 덮어쓰기만으로는 사이트가 변경되지 않습니다.

포함된 엑셀은 이번에 보내주신 파일 그대로입니다.
이후 같은 양식의 엑셀을 계산·저장한 뒤 data/MY_HI_AWARD_DATA.xlsx로 교체하고 Commit/Push하세요.
엑셀은 수식의 계산 결과와 연결 지급표가 저장되어 있어야 합니다.
실적 기준일은 엑셀 변경 커밋의 한국 날짜를 기준으로 직전 평일로 정해집니다.
새 백데이터가 없으면 실적 기준일도 바뀌지 않습니다.

반영 내용:
- 새 '도전 목표' 및 주차별 시상금 열을 연결
- 1·2·3·4~5주차 실적과 시상금, 공개 주차 합산
- 엑셀 지급표에 따른 월 누계 구간별 주차 재계산
- 하이스타·하이포인트 기존 시트 연결 유지
- 기존 디자인 유지

검증: 플래너 16,774명의 주차별 시상금 및 누계가 제공 엑셀과 일치.
이 ZIP에는 신규 기준일이 잘못 고정되지 않도록 자동 생성 JSON을 넣지 않았습니다.
GitHub Actions가 업로드된 엑셀로 새 JSON을 생성하고 검증 후 배포합니다.
