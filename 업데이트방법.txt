MY HI-AWARD - 충돌 방지 자동 업데이트 버전

[최초 1회]
1. GitHub Desktop에서 현재 Merge 중이라면 Abort merge를 누릅니다.
2. 이 ZIP의 전체 내용을 기존 저장소 폴더에 덮어씁니다.
3. 저장소 폴더 안의 RESET_ONCE.bat를 한 번 실행합니다.
   - 기존 data/planners/*.json 및 data/meta.json을 삭제합니다.
   - 이 파일들은 앞으로 GitHub main 브랜치에 저장하지 않습니다.
4. GitHub Desktop에서 변경사항 전체를 Commit 후 Push 합니다.
5. GitHub 웹사이트 > 저장소 Settings > Pages > Build and deployment > Source를
   'GitHub Actions'로 선택합니다. (최초 1회)
6. Actions에서 'Build & deploy MY HI-AWARD'가 성공하면 배포 완료입니다.

[매일 업데이트]
1. 최신 엑셀 파일명을 MY_HI_AWARD_DATA.xlsx 로 맞춥니다.
2. 저장소의 data/MY_HI_AWARD_DATA.xlsx 하나만 덮어씁니다.
3. GitHub Desktop에서 Commit -> Push 합니다.
4. GitHub Actions가 자동으로 플래너 JSON/마감일을 생성하여 Pages에 배포합니다.

※ data/planners와 data/meta.json은 GitHub 저장소에 커밋하지 않으므로
   수백 개 JSON 충돌이 다시 발생하지 않습니다.
